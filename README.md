# 동탄 은혜푸드마켓 홈페이지

서버나 데이터베이스 없이 파일만으로 도는 정적 홈페이지입니다.

- 저장소: https://github.com/a57730884-pixel/dongtan-eunhye-foodmarket
- 공개 주소: https://a57730884-pixel.github.io/dongtan-eunhye-foodmarket/

## 1. 바로 보기

```bash
python -m http.server 5174
```

브라우저에서 `http://localhost:5174` 을 엽니다.
(`index.html` 을 더블클릭해 열어도 대부분 보이지만, 데이터 분석의 **예시 파일로 체험하기**는 서버로 열었을 때만 동작합니다.)

## 2. 디자인 기준

Kristián Balco 의 Bartfay 웹디자인 구성을 기준으로 잡았습니다(색·사진·문구는 모두 새로 만든 것입니다).

| 항목 | 값 |
|---|---|
| 서체 | 한글 Noto Sans KR (제목 300, 본문 400) · 숫자와 영문 눈썹 Nunito |
| 색 | 흰색 `#ffffff` · 옅은 회색 `#f7f5f2` · `#efece7` · 먹색 `#1a1a1a` · 본문 `#54524d` · 황갈색 `#c8a27a`(장식) `#8a6640`(글자·단추) |
| 제목 | 왼쪽에 2px 황갈색 세로 바, 가는 글씨(300), 위에 영문 눈썹 |
| 첫 화면 | 흰 바탕에 왼쪽 글 · 오른쪽 사진 3장 슬라이더(5:4) · `01/03` 카운터와 화살표 |
| 속 페이지 | 사진 위에 흰 장막을 덮은 밝은 배너 + 하위 메뉴 알약 버튼 |
| 블록 | 옅은 회색 판 위의 사진 카드 3장(사진 위 · 흰 설명 아래) · 큰 숫자 + 선 아이콘 · 사진 갤러리 |
| 갤러리 | 4단 사진 격자 · 누르면 흰 바탕 위에 크게 보기(← → · Esc) |
| 모서리 | 각지게(0) · 그림자 대신 가는 선과 여백으로 나눔 |
| 푸터 | 4단 (기관 · 연락처 · 메뉴 · 사업) |

## 3. 화면 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 — 사진 슬라이더 · 세 가지 나눔 방식 · 왜 은혜푸드마켓인가 · 숫자로 보는 나눔 · 함께한 순간들 · 언론 보도 · 기탁 문의 |
| `about.html` | 사업안내 — 인사말 · 비전/목표 · 운영체계 · 걸어온 길(연혁) · 오시는 길 |
| `donate.html` | 기탁 · 후원 — 기탁 방법(4단계) · 가능/불가 물품 · 세제 혜택 · 현금 후원 · 함께한 기탁처 |
| `use.html` | 이용안내 — 이용 대상(우선순위) · 푸드마켓/푸드뱅크/그냥드림 · 신청 절차 · 담당 지역 |
| `archive.html` | 아카이브 — 언론 보도(원문 링크) · 활동 소식 · 운영 실적 · 공지. 분류 탭 · 연도 · 검색 · 쪽 나누기 |
| `transparency.html` | 투명 공개 — 연도별/월별 기부물품, 유형별 · 기탁처별, 이용 현황, 수입/지출. 모든 그래프에 표 보기 · PNG 저장 |
| `analyze.html` | 데이터 분석 — 엑셀/CSV 끌어다 놓기 → 요약 · 추이 · 항목별 그래프 · 피벗 · 원본 표 · 결과 엑셀 저장 |

### 공통 파일

| 파일 | 내용 |
|---|---|
| `js/config.js` | **기관 정보 한 곳** — 이름 · 주소 · 전화 · 운영시간 · 담당 지역 · 후원 계좌 |
| `js/layout.js` | 헤더(사진 위에서는 투명, 내리면 짙은 회색) · 모바일 메뉴 · 4단 푸터 · 숫자/날짜 형식 |
| `js/charts.js` | 차트 도우미 — 얇은 막대, 계열 1개는 황갈색 · 2개는 회색+황갈색 듀오톤 · 3개 이상은 검증된 팔레트, 표 보기, PNG 저장 |

| 파일 | 내용 |
|---|---|
| `data/archive.js` | 아카이브 글. `cat` 은 press/activity/report/notice, 언론 기사는 `url`, 직접 쓴 글은 `body` |

| `js/gallery.js` | "함께한 순간들" 사진 목록과 설명, 크게 보기 |

## 4. 사진

`images/` 의 사진은 모두 **실제 현장 사진**입니다(2019~2026년 기탁 전달식 · 물류 상차 · 사업장 · 창립 10주년).
바꿀 때는 **같은 파일 이름으로 덮어쓰고**, HTML 의 `?v=` 숫자를 하나 올리면 됩니다(브라우저가 옛 사진을 기억하지 않도록).

배너는 사진 위에 흰 장막을 덮어 글을 얹으므로, **현수막 글자가 큰 부분은 잘라 내고** 밝은 윗부분을 씁니다.

| 파일 | 쓰이는 곳 | 권장 |
|---|---|---|
| `hero-10th.jpg` `hero-store.jpg` `hero-share.jpg` | 첫 화면 슬라이더 | 5:4, 가로 1600 |
| `banner-*.jpg` | 각 페이지 상단 | 3.5:1 띠, 가로 1920 (analyze 만 1400) |
| `card-market.jpg` `card-bank.jpg` `card-gnd.jpg` | 첫 화면의 나눔 방식 카드 · `use.html` 의 카드 썸네일 | 4:3, 가로 1200 |
| `place-front.jpg` | `about.html` 오시는 길 | 3:2, 가로 1400 |
| `images/gallery/g01~g12.jpg` | 함께한 순간들 | 4:3, 가로 1280 · 목록용 `-t.jpg` 는 가로 560 |
| `story-1~4.jpg` `hero-1~3.jpg` | 지금은 쓰지 않음 (이전 판 사진) | — |

새로 만들 때:

```bash
python tools/prep_photos.py <원본 폴더>
```

톤(채도 · 대비 · 입자 · 비네팅)을 한 번에 맞춰 `images/photo/` 에 저장합니다.

## 5. 데이터 분석 (드래그 앤 드롭)

- 파일은 **브라우저 안에서만** 읽습니다. 서버로 보내지 않습니다.
- 첫 줄이 항목 이름이면 어떤 표든 됩니다. 제목 줄이 위에 있어도 머리글을 찾아냅니다.
- 열의 성격을 스스로 가려냅니다: 날짜 / 숫자 / 범주 / 글. 이름에 금액·비용·수입·지출이 들어간 열은 금액으로 보고 억·만 단위로 보여 줍니다. 단가·비율처럼 더하면 안 되는 열은 평균으로 다룹니다.
- 만드는 것: 요약 타일 → 기간별(일/월/연) 추이 → 구분(기탁/배분, 수입/지출)별 추이 → 항목별 합계(상위 9 + 기타) → 피벗 → 원본 표 → 결과 엑셀.
- `samples/` 에 예시 파일과 입력 양식이 있습니다. `python tools/make_sample_xlsx.py` 로 다시 만듭니다.
