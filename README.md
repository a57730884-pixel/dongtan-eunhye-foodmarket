# 동탄 은혜푸드마켓 홈페이지

광명푸드뱅크마켓센터(gmfm1377.net)의 메뉴 구성(사업안내 · 기탁자 · 이용 및 물품지원 · 갤러리게시판 · 오시는길)을 바탕으로,
**투명성과 신뢰**를 앞세워 새로 지은 정적 홈페이지입니다. 서버나 데이터베이스 없이 파일만으로 돌아갑니다.

## 1. 바로 보기

```bash
python -m http.server 5174
```

브라우저에서 `http://localhost:5174` 을 엽니다.
(`index.html` 을 더블클릭해 열어도 대부분 보이지만, 데이터 분석의 **예시 파일로 체험하기**는 서버로 열었을 때만 동작합니다.)

## 2. 화면 구성

| 파일 | 내용 |

## 3. 데이터 분석 (드래그 앤 드롭)

- 파일은 **브라우저 안에서만** 읽습니다(SheetJS). 서버로 보내지 않습니다.
- 첫 줄이 항목 이름이면 어떤 표든 됩니다. 제목 줄이 위에 있어도 머리글 줄을 찾아냅니다.
- 열의 성격을 스스로 알아냅니다: 날짜 / 숫자 / 범주(값이 몇 가지로 정해진 열) / 글.
  이름에 "금액 · 원 · 비용 · 수입 · 지출"이 들어간 숫자 열은 금액으로 보고 억 · 만 단위로 표시합니다.
- 자동으로 만드는 것: 요약 타일 → 기간별(일/월/연) 추이 → 구분(기탁/배분, 수입/지출)별 추이 → 범주별 합계(상위 9 + 기타) → 피벗(행 · 나누기 · 값 · 계산) → 원본 표(정렬).
- `samples/` 에 예시 파일과 입력 양식이 있습니다. `python tools/make_sample_xlsx.py` 로 다시 만들 수 있습니다.

## 4. 그래프 색과 형태

`js/charts.js` 의 색 순서(`#1baf7a → #eb6834 → #2a78d6 → #eda100 → #4a3aa7 → #e87ba4`)는 색약 · 저시력 검증을 통과한 순서입니다.
단일 계열은 브랜드 녹색 하나만 씁니다. 막대는 24px 이하, 데이터 끝만 둥글게, 선 2px, 격자는 옅은 실선. 모든 그래프는 표로도 볼 수 있어 색을 못 보는 분도 같은 정보를 얻습니다.
